TIEN MEE — КАТАЛОГ ЭКСКУРСИЙ И МОРСКИХ УСЛУГ

В архиве:
- excursions.js — каталог из 10 программ/услуг: названия, цены, описания, расписание, программы, ссылки WhatsApp.
- images/ — изображения для карточек каталога.

КАК ЗАГРУЗИТЬ В GITHUB
1. Распакуйте архив.
2. Загрузите файл excursions.js в корень сайта рядом с index.html и app.js.
3. Загрузите папку images целиком, сохранив названия файлов.
4. В index.html подключите excursions.js перед app.js:
   <script src="excursions.js"></script>
5. Интерфейс app.js должен читать window.TIENMEE_EXCURSIONS и строить карточки/календарь. Сам по себе файл данных не меняет экран приложения.

РАСПИСАНИЕ
- Если в исходной карточке были указаны дни, сохранены эти дни.
- Если дни не были указаны, days: 'daily' означает возможность выбрать любой день; фактическую доступность подтверждает менеджер.
- Цены и описания перенесены из предоставленных материалов. Неуказанные цены оставлены пустыми.

ФОТОГРАФИИ
- В папке images лежат первые изображения для каталога. Некоторые — маршрутные коллажи/общие изображения, а не отдельные фотографии каждой программы. Их можно заменить позже, сохранив имена файлов или обновив поле image в excursions.js.

ВАЖНО
Этот пакет содержит данные и изображения каталога, но не заменяет текущие index.html и app.js и не подключает карточки автоматически. Для отображения всех программ потребуется интеграция каталога в интерфейс Mini App.
